# Standing Start

*Every legend starts from zero.*

Standing Start est un mode carrière pour **Automobilista 2** : tu crées un pilote, tu pars du karting de location et tu montes les échelons, de contrat en contrat, jusqu'à la F1.

## Télécharger

Va dans l'onglet [**Releases**](../../releases/latest) et télécharge le fichier `StandingStart-X.Y.Z.zip` de la dernière version.

1. Clic droit sur le zip, puis **Extraire tout**, dans le dossier de ton choix.
2. Lance `StandingStart.exe` (le premier lancement est un peu long). Aucune installation n'est nécessaire.
3. Ta carrière est enregistrée dans `carriere.db`, à côté de l'application.

Windows peut afficher « Windows a protégé votre ordinateur » : l'application n'est pas encore signée. Clique sur **Informations complémentaires**, puis **Exécuter quand même**.

## Mises à jour

Quand une nouvelle version est publiée ici, l'application te le propose elle-même (encadré « Mettre à jour » sur l'accueil). Ta carrière est conservée, avec une copie de sécurité.
